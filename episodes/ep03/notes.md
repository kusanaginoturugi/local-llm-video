# 第3弾「声で話しかけると声で返事をする AI」の制作メモ

記事と台本を書く前の、決まったことと実測の控え。コードは ~/src/voice-chat。

## 決まったこと

- 話しかけ方はキーを押して開始、もう一度押して終了（第2弾と同じトグル）。
  無音で自動に区切る方式は、言いよどんだだけで送られてしまい喋りにくいので使わない。動画でアマチュア無線（オーバー）の例えは使わない（古くて伝わらない）。
- 返事の途中でキーを押すと、読み上げを止めて聞く側に回る。
- 「ずんだもんに切り替えて」「めたんに代わって」でキャラが交代する（characters.toml）。会話は引き継ぐ。
- 返事の最後に相手への質問を 1 つ添えて、会話を続けやすくする。「またね」などのときは質問せずに締める。
- モデルは第1弾・第2弾と同じ gemma-4-E4B-it（qat）。
- キーの例は SUPER+SHIFT+H（音声入力の SUPER+H にシフトを足す）。動画では「空いているキーに」と言うだけにする。

## 台本に入れる：人物像を書かないとずんだもんにならない

2026-10-22、gemma-4-E4B-it-qat、temperature 0、thinking なしで試した結果。

1. 人物像なしで「ずんだもんってどんなキャラ？」→ 枝豆モチーフで元気、までは知っている。
   一人称は「ずんだもん」か「あたし」と答え、「〜のだ」は出てこない。
2. 「四国めたんってどんなキャラ？」→「知識の中には具体的な情報がありません」。
3. システムプロンプトを「あなたはずんだもんです。」だけにして雨の日の過ごし方を聞く →
   「ずんだもんだ！✨ わたくしは、ずんだもんだ！って呼ばれる、ずんだ餅みたいなAIなんだ。」
   絵文字と見出し・箇条書きの長い返事。「〜のだ」は一度もない。
4. 人物像（一人称ボク、語尾〜のだ）と会話の決まり（短く、記号なし、最後に質問）を渡す →
   「雨の日は家でゆっくりするのがおすすめなのだ。映画を見たり、本を読んだりするのも楽しいのだ。君は雨の日に何をすることが好きかな？」

見せ方: 3 と 4 を、ずんだもんの声でそのまま読み上げて比べる。小さなモデルはキャラの細かい知識を持っていないので、
具体的に書いて渡すと演じる、というシステムプロンプトの効き目が聞くだけで分かる。

人物像は 2026-10-22 に、VOICEVOX 公式「ボイボ寮」のプロフィールと呼び方表、zunko.jp のキャラクター紹介にそろえた
（~/src/voice-chat/characters.toml）。公式の主な点:

- ずんだもん: ずんだ餅の精、年齢の概念なし、やや不幸属性、趣味はその辺をふらふらすること・自分を大きく見せること。
  一人称「ずんだもん」「僕」、二人称「オマエ」「みんな」。語尾「〜のだ」はボイボ寮には書かれていない（よく知られた話し方）
- 四国めたん: 高等部二年生 17 歳、弓道部、常に金欠、趣味は中二病妄想、若干ツンデレ、誰にでも遠慮しないので基本タメ口。
  一人称「わたくし」、二人称「貴女(たち)」「アンタ(ら)」。「〜ですわ」のお嬢様言葉は公式ではない
- 春日部つむぎ: 埼玉の高校に通う 18 歳のギャル、やんちゃに見えて実は真面目、カレー好き、動画配信サイト巡回。
  一人称「あーし」、二人称「きみ」「オタクくん」。ずんだもん先輩・めたん先輩と呼ぶ

ガイドライン（https://zunko.jp/guideline.html）は「キャラのイメージを著しく悪化させなければＯＫ」。

そろえたあとの返事の例: めたんに「最近お金がなくてさ」→「はぁ、また金がないとか、アンタって本当に困ってるのね。
わたくしだって金欠なんだから、共感するわけじゃないけど。」（金欠・ツンデレ・アンタが出る）。
つむぎに「めたんってどんな人？」→「めたん先輩は、結構真面目で優しいんだよ」。呼び方は合うが、中身は LLM の作り話
（ほかのキャラの人物像は渡していない）。

## 記事と動画に入れる：VOICEVOX の入れ方

第1弾・第2弾は llama.cpp と whisper.cpp の入れ方から書いたので、VOICEVOX も入れ方から書く。
使うのは画面のあるエディタではなく、裏で動く VOICEVOX ENGINE（HTTP の API で声を作る）。

手元の環境は Docker の CPU 版（voicevox/voicevox_engine:cpu-latest、イメージ 4.31GB、エンジン 0.25.2）。
コンテナ名 voicevox、--restart unless-stopped で、パソコンを起動すると一緒に立ち上がる。

```sh
# Docker を入れる（Arch 系）
sudo pacman -S docker
sudo systemctl enable --now docker

# 公式 README のとおり。127.0.0.1 にだけ開く（外から使えないように）
docker pull voicevox/voicevox_engine:cpu-latest
docker run -d --name voicevox --restart unless-stopped \
  -p '127.0.0.1:50021:50021' voicevox/voicevox_engine:cpu-latest

# 動いたか確かめる
curl http://127.0.0.1:50021/version
curl -s http://127.0.0.1:50021/speakers   # 声の一覧（スタイル ID はここで分かる）
```

- 公式 README は `docker run --rm ...`（止めると消える）。常駐させたいので --name と --restart に変えた。
- GPU 版は voicevox/voicevox_engine:nvidia-latest に `--gpus all`。VRAM をどれだけ使うか、速くなるかは未測定（見どころ候補）。
- Docker を使わない方法: 公式リリース（https://github.com/VOICEVOX/voicevox_engine/releases/latest）からエンジン単体を落とす。
  エディタ（https://voicevox.hiroshiba.jp/）を起動している間もエンジンが 50021 で動く。
- 声を作る流れは 2 段: /audio_query（文章 → 読み方とアクセント）→ /synthesis（→ WAV）。台本では curl で見せる。
- 利用規約: 声ごとに規約があり、動画などで使うときは「VOICEVOX:ずんだもん」のようにクレジットを書く。
- 公式 README には /streaming_synthesis（合成しながら少しずつ返す）があるが、手元の 0.25.2 にはまだない
  （/openapi.json で確認）。新しい版で使えれば、声が出るまでをさらに縮められるかもしれない。

## 実測（話し終えてから声が出るまで、文章で話しかけた場合）

| | 返事の最初の文字 | 声が出始める |
|---|---|---|
| 1 回目（モデルの読み込みを含む） | 2.88 秒 | 3.23 秒 |
| 2 回目 | 0.06 秒 | 0.83 秒 |
| 3 回目 | 0.06 秒 | 0.58 秒 |

残りの時間はほとんど VOICEVOX（Docker の CPU 版）が最初の 1 文を合成する時間。GPU 版との比較は未測定。
このときの GPU 使用量は 8.4GB（whisper-server と E4B を読み込んだ状態）。

## 記事と台本の分担（2026-10-23 決定）

記事はゆっくり読むものなので詳しく書く（システムプロンプトの全文と書き方のコツ、curl での投げ方、履歴、stream の中身）。
台本は簡単な説明にとどめ、詳しくは記事へ誘導する。

質問の語尾の決まり（「質問するときも〜なのだ？」）の効き目: 8 つの話しかけ × 3 回、temperature 0.7。
決まりなし 24 個中 18 個（75%）が「〜のだ？」、決まりあり 31 個中 30 個（97%）。決まりなしでは「〜なのかしら？」も出た。
履歴つきでも「映画ならボクも好きだぞ」と崩れることはある。システムプロンプト全文は 318 トークン、読み込み 90 ミリ秒。

## CPU 版と GPU 版の VOICEVOX（2026-10-22 23:20 ごろ）

nvidia-container-toolkit 1.20.1 を入れ、voicevox/voicevox_engine:nvidia-latest（0.25.2、約 3GB）を 50022 番に立てて比べた。
ログに「CUDA (device_id=0)を利用します」。5 つの話しかけ、モデルは読み込み済み、合成は温めてから。

| | 全部待つ（中央値） | 1 文ずつ（中央値） |
|---|---|---|
| CPU 版 | 1.83 秒 | 0.95 秒 |
| GPU 版 | 0.38 秒 | 0.22 秒 |

- GPU 版は 71 字の返事を丸ごと 0.09 秒ほどで声にする。待ち時間はほぼ LLM（返事を書き終えるまで 0.21〜0.33 秒）だけになる
- GPU 版の VRAM は 770 MiB。全部載せて 9,325 / 12,282 MiB
- CPU 版の数字は 1 回目（1.70 / 0.85）とこの回（1.83 / 0.95）で少し揺れる

## 見つけたこと

- 無音や雑音だけを録ると、Whisper が「(音楽)」と書き、ずんだもんが「ノリノリなのだ」と答えた。注記だけなら聞き取れなかった扱いにした。
- 交代のときのひとことは決まり文句（LLM を通していない）。
- めたんの口調: 解説役のめたんは「です・ます」、voice-chat のめたんは公式どおりのタメ口（アンタ、わたくしだって金欠）。この違いをネタにする（2026-10-22 決定）。例「公式の設定だと、わたくし本当はタメ口なのよ……動画では猫をかぶっていますの」
