# 第3弾「声で話しかけると声で返事をする AI」の制作メモ

記事と台本を書く前の、決まったことと実測の控え。コードは ~/src/voice-chat。

## 決まったこと

- 話しかけ方はキーを押して開始、もう一度押して終了（第2弾と同じトグル）。
  無音で自動に区切る方式は、アマチュア無線の「オーバー」のような合図がないと喋りにくいので使わない。
- 返事の途中でキーを押すと、読み上げを止めて聞く側に回る。
- 「ずんだもんに切り替えて」「めたんに代わって」でキャラが交代する（characters.toml）。会話は引き継ぐ。
- 返事の最後に相手への質問を 1 つ添えて、会話を続けやすくする。「またね」などのときは質問せずに締める。
- モデルは第1弾・第2弾と同じ gemma-4-E4B-it（qat）。
- キーの例は SUPER+SHIFT+H（音声入力の SUPER+H にシフトを足す）。動画では「空いているキーに」と言うだけにする。

## 台本に入れる：人物像を書かないとずんだもんにならない

2026-10-22、gemma-4-E4B-it-qat、temperature 0、thinking なしで試した結果。

1. 人物像なしで「ずんだもんってどんなキャラ？」→ 枝豆モチーフで元気、までは知っている。
   一人称は「ずんだもん」か「あたし」と答え、「〜のだ」は出てこない。
2. 「四国めたんってどんなキャラ？」→「知識の中には具体的な情報がありません」。
3. システムプロンプトを「あなたはずんだもんです。」だけにして雨の日の過ごし方を聞く →
   「ずんだもんだ！✨ わたくしは、ずんだもんだ！って呼ばれる、ずんだ餅みたいなAIなんだ。」
   絵文字と見出し・箇条書きの長い返事。「〜のだ」は一度もない。
4. 人物像（一人称ボク、語尾〜のだ）と会話の決まり（短く、記号なし、最後に質問）を渡す →
   「雨の日は家でゆっくりするのがおすすめなのだ。映画を見たり、本を読んだりするのも楽しいのだ。君は雨の日に何をすることが好きかな？」

見せ方: 3 と 4 を、ずんだもんの声でそのまま読み上げて比べる。小さなモデルはキャラの細かい知識を持っていないので、
具体的に書いて渡すと演じる、というシステムプロンプトの効き目が聞くだけで分かる。

注意: 人物像は公式の設定を写したものではない。確かめられたのは、ずんだもんの語尾「〜のだ」、
春日部つむぎの「埼玉の高校に通う 18 歳のギャル」「一人称あーし」まで。動画で見せる前に公式プロフィールとそろえる。
ガイドライン（https://zunko.jp/guideline.html）は「キャラのイメージを著しく悪化させなければＯＫ」。

## 実測（話し終えてから声が出るまで、文章で話しかけた場合）

| | 返事の最初の文字 | 声が出始める |
|---|---|---|
| 1 回目（モデルの読み込みを含む） | 2.88 秒 | 3.23 秒 |
| 2 回目 | 0.06 秒 | 0.83 秒 |
| 3 回目 | 0.06 秒 | 0.58 秒 |

残りの時間はほとんど VOICEVOX（Docker の CPU 版）が最初の 1 文を合成する時間。GPU 版との比較は未測定。
このときの GPU 使用量は 8.4GB（whisper-server と E4B を読み込んだ状態）。

## 見つけたこと

- 無音や雑音だけを録ると、Whisper が「(音楽)」と書き、ずんだもんが「ノリノリなのだ」と答えた。注記だけなら聞き取れなかった扱いにした。
- 交代のときのひとことは決まり文句（LLM を通していない）。
